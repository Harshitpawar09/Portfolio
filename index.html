SiteVision AI

Construction Material Detection & Inventory Management

Problem

Construction sites struggle to track materials accurately, leading to manual counts, costly errors, and poor inventory visibility.

Solution

An AI-powered inventory management system using custom-trained YOLOv8 models to detect and count construction materials directly from site imagery, paired with an interactive monitoring dashboard.

Key Features
  • Custom-trained YOLOv8 models for material detection
  • Dataset annotation, preprocessing & model training pipeline
  • Automated inventory counting from images
  • Downloadable reporting and an interactive Streamlit dashboard
Impact & Results

Replaced manual material counting with automated image-based analysis, improving inventory accuracy and monitoring speed on site.

Python YOLOv8 OpenCV Streamlit
GitHub Repository

PaudhaMitra

AI-Powered Plant Care Application

Problem

Farmers and gardeners struggle to diagnose plant diseases early, leading to crop loss and overuse of chemical treatments.

Solution

A plant care platform that detects diseases from images using a trained machine learning model and combines it with weather-based insights to deliver actionable health recommendations.

Key Features
  • Image-based plant disease detection using Deep Learning
  • Integration of local weather data for context-aware treatment
  • Actionable recommendations and organic treatment guides
  • Responsive dashboard with historical diagnostics tracking
Impact & Results

Helped users achieve early plant disease detection and provided ecological remedies, reducing crop damage.
